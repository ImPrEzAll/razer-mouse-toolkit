【日常就用这一个】

    双击  razerui.cmd

    浏览器会自动打开控制台，改完点"应用"立即写进鼠标板载。
    关掉窗口就结束，不用一直开着，也不占后台。


【界面里能改什么】

    · 7 个按键映射
      复制 / 粘贴 / 剪切 / 撤销 / 保存 / 全选
      音量加减 / 静音 / 多媒体 / 鼠标按键 / 禁用
      自定义组合键（写 ctrl+shift+t 或 f13 这种）
    · DPI（滑块 + X/Y 分开设）
    · 5 个 DPI 档位（逐个编辑、可切换活动档）
    · 灯效（常亮 / 呼吸 / 亮度 0-255 / 一键关闭）
    · 回报率（125 / 500 / 1000）

    注意：回报率能写、能回读，但这只鼠标物理上限是 125Hz，
          设成 500 或 1000 实际还是 125Hz。


【不想开界面，用命令行】

  改侧键：
      mapbtn.cmd dump                 看当前映射
      mapbtn.cmd set forward ctrl+c   前侧键 = 复制
      mapbtn.cmd set back ctrl+v      后侧键 = 粘贴
      mapbtn.cmd set back key:f13     改成单个按键
      mapbtn.cmd set back default     这一个键恢复默认
      mapbtn.cmd backup               备份整张表
      mapbtn.cmd restore              从备份还原

  改 DPI / 回报率：
      razerctl.cmd info               看固件、序列号、DPI、回报率
      razerctl.cmd dpi 1600           设 DPI
      razerctl.cmd poll 500           设回报率

  测实际回报率：
      measure_rate.cmd                三档全测（每档 3 秒，需画圈）
      measure_rate.cmd 5              每档 5 秒
      measure_rate.cmd 3 --rate current   不切档，测当前设定
      measure_rate.cmd 2 --selftest   只跑自证，不用动鼠标


【出问题怎么办】

  鼠标按键错乱 / 左键失灵 —— 全部恢复成出厂功能：
      双击  reset_to_normal.cmd

  左键已经点不动了？用键盘：
      Win + R，cd 到本目录，然后运行
      py -3.10 reset_to_normal.py

  侧键映射丢了（比如不小心开了雷云）：
      mapbtn.cmd restore


【一条铁律】

    别开雷云（Razer Synapse）。

    它一启动就会把自己那套默认配置下发下去，把这里设的东西
    全部冲掉（映射、灯效都会被改）。

    已经禁用了它的开机自启。如果不小心点开了，
    关掉它，然后跑一次  mapbtn.cmd restore  就好。

    也不要卸载雷云 —— RzDev_0098.sys 这个驱动是鼠标控制接口的
    依赖，卸载很可能连带删掉它，那时本工具会直接失效。


【写在最后】

    这个工具不依赖雷云，直连鼠标的 HID 接口。
    所有设置都写进鼠标板载存储，拔下来插到别的电脑也保持
    （回报率除外，那个是设备固件层面锁死的）。
